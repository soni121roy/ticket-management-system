# 🚂 Ticket Management System

A modern Railway Ticket Booking System with clean UI and Local Storage.

**🔗 Live Demo:** https://soni121roy.github.io/ticket-management-system/

### 📸 Preview
![Preview](./screenshot.png)

### ✨ Features
- Book Ticket with Name, Seat No, Date, From & To Location
- View Booking History
- Responsive Design
- Local Storage Supported
- Railway Station Themed UI

HTML5 | CSS3 | JavaScript | GitHub Pages
